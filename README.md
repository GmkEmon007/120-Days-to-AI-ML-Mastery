# 🚀 120 Days of AI & Machine Learning Mastery

Welcome to my **120 Days of AI/ML** challenge repository! This space documents daily learning notes, code implementations, experiments, and end-to-end projects as I journey from fundamental mathematics and classical machine learning to modern deep learning, LLMs, and production MLOps.

## 🛠️ How to Use This Repository

1. **Daily Routine:**
   - Open today's folder under `Daily-Notes/Day-XXX/`.
   - Update the `README.md` with today's topic, notes, key takeaways, and reflections.
   - Place any code, scripts, or Jupyter notebooks into `Daily-Notes/Day-XXX/code/`.
   - Check off the day in the [Progress Tracker](#-challenge-roadmap--progress-tracker) table above.
2. **Projects:**
   - Build consolidated, portfolio-ready projects inside [`projects/`](./projects/).
3. **Commit Regularly:**
   ```bash
   git add .
   git commit -m "Day XXX: Completed [Topic Name]"
   git push origin main
   ```
